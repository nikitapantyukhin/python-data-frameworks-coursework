# Сравнительный анализ влияния ручного и искусственного обогащения данных на качество и устойчивость обучения моделей машинного обучения

Исследовательский проект по дисциплине «Фреймворки для анализа данных на Python». Цель работы — сравнить, как ручное, синтетическое и совместное обогащение влияет на качество и устойчивость моделей для двух разных типов данных: русскоязычных текстов и изображений с объектной разметкой.

## Датасеты

| Датасет | Тип и объём | Задача | Источник и условия | Особенности |
| --- | ---: | ---: | ---: | ---: |
| Geo Reviews Dataset 2023 | 500 000 русскоязычных отзывов | Бинарная классификация тональности текста | [Оригинал](https://github.com/yandex/geo-reviews-dataset-2023), MIT; [Parquet-копия](https://huggingface.co/datasets/d0rj/geo-reviews-dataset-2023) | Предварительная метка выводится из рейтинга: 1–2 — negative, 4–5 — positive; рейтинги 0 и 3 требуют отдельного решения |
| Hard Hat Workers v10 (`raw_AllClasses`) | 7 035 изображений, 27 039 Bounding Boxes | Object Detection | [Roboflow Universe](https://universe.roboflow.com/joseph-nelson/hard-hat-workers/dataset/10); в метаданных указано Public Domain | Классы `head`, `helmet`, `person`; происхождение и права на отдельные изображения требуют независимой проверки |

Исходные данные не входят в репозиторий. Инструкции по их получению и ожидаемая структура приведены в [data/README.md](data/README.md), подробные сведения — в [docs/datasets.md](docs/datasets.md).

## Методология

Для каждого датасета планируется сравнить четыре режима обучения при одинаковом разбиении и протоколе оценки:

1. только исходная рабочая выборка;
2. исходная выборка с новыми вручную размеченными реальными объектами;
3. исходная выборка с синтетическим обогащением;
4. совместное ручное и синтетическое обогащение.

Разбиение на train/validation/test должно быть зафиксировано до обогащения. Производные варианты объектов из validation/test не допускаются в train. Будущие модели, гиперпараметры и объём добавленных данных должны быть сопоставимы между режимами. Методологические решения и открытые вопросы зафиксированы в [docs/methodology.md](docs/methodology.md).

## Установка

Команды предназначены для Linux/WSL и выполняются из корня проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Получение данных

Geo Reviews загружается воспроизводимым скриптом по точному имени Parquet-файла:

```bash
python scripts/download_geo_reviews.py
```

Hard Hat Workers необходимо скачать вручную со страницы [версии 10](https://universe.roboflow.com/joseph-nelson/hard-hat-workers/dataset/10) в формате YOLOv8 и распаковать в `data/raw/hard_hat/`. Ожидаемые каталоги: `train/`, `valid/`, `test/`, каждый с `images/` и `labels/`. Подробности и контрольные количества указаны в [data/README.md](data/README.md).

### Запуск EDA

```bash
source .venv/bin/activate
jupyter lab
```

Откройте ноутбуки и выполняйте ячейки сверху вниз. Для автоматической проверки без сохранения outputs в исходные файлы:

```bash
mkdir -p .local/executed_notebooks
jupyter nbconvert --to notebook --execute notebooks/01_geo_reviews_eda.ipynb \
  --output 01_geo_reviews_eda.executed.ipynb \
  --output-dir .local/executed_notebooks \
  --ExecutePreprocessor.timeout=600
jupyter nbconvert --to notebook --execute notebooks/02_hard_hat_eda.ipynb \
  --output 02_hard_hat_eda.executed.ipynb \
  --output-dir .local/executed_notebooks \
  --ExecutePreprocessor.timeout=600
```

## Основные результаты EDA

- Geo Reviews: 500 000 строк и пять исходных столбцов; 970 пропусков `name_ru`; 431 675 положительных и 46 439 отрицательных отзывов по предварительному бинарному правилу; отношение классов 9,30:1.
- Повторяются 75 уникальных текстов: всего 190 строк в группах, 115 лишних копий. Все копии одного нормализованного текста должны оставаться в одном split.
- Hard Hat Workers: 7 035 читаемых JPEG и 27 039 технически корректных YOLO-рамок — 6 677 `head`, 19 747 `helmet`, 615 `person`.
- Класс `person` составляет 2,27% рамок и требует дополнительного аудита; 58,43% всех рамок занимают менее 1% кадра.
- Точных дубликатов изображений по SHA-256, в том числе между train/valid/test, не обнаружено.

Полные таблицы, методика проверок и агрегированные графики находятся в [reports/eda_summary.md](reports/eda_summary.md).

## Воспроизводимость и политика артефактов

- Проверенная среда: Python 3.12; допустимые диапазоны библиотек закреплены в `requirements.txt`.
- Ноутбуки находят корень проекта по каталогу `data/raw` и не содержат абсолютных пользовательских путей.
- Публичные `.ipynb` хранятся без outputs. Результаты представлены в Markdown-отчёте и агрегированных PNG.
- Выполненные копии создаются в `.local/executed_notebooks/` и не попадают в Git.
- Визуализации с исходными фотографиями Hard Hat Workers сохраняются локально, поскольку права на отдельные изображения и допустимость публикации лиц не подтверждены.
- Для проверки результатов требуется та же версия датасетов. Контрольные инварианты перечислены в [data/README.md](data/README.md).
