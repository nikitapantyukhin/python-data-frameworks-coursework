# Сравнительный анализ методов обогащения данных

Курсовая работа по дисциплине «Фреймворки для анализа данных на Питоне».

**Тема:** «Сравнительный анализ влияния ручного и искусственного обогащения данных на качество и устойчивость обучения моделей машинного обучения».

**Участники:** Смирнов Константин Алексеевич, Пантюхин Никита Олегович. Группа М8О-201БВ-25.

## Цель

Проект сравнивает исходные выборки с ручным, искусственным и совместным обогащением при одинаковых разбиениях и правилах оценки. Рассматриваются русскоязычные отзывы и изображения жестов рук.

## Датасеты

| Датасет | Задача | Рабочая выборка | Ручное обогащение |
| --- | --- | ---: | ---: |
| [Geo Reviews Dataset 2023](https://github.com/yandex/geo-reviews-dataset-2023) | Бинарная тональность отзывов | 1 000 отзывов | 200 отзывов Otzyvru |
| [HaGRIDv2](https://github.com/hukenovs/hagrid) | Классификация и детекция жестов | 34 000 изображений | 200 изображений [CNGR/CN_Gesture_Recognition](https://huggingface.co/datasets/CNGR/CN_Gesture_Recognition) |

Основная текстовая выборка содержит отзывы о KFC, Burger King, «Вкусно — и точка» и Rostic's, сбалансированные по двум классам. Дополнительные изображения HaGRID относятся к классам `like`, `dislike`, `palm` и `fist` — по 50 каждого класса.

## Выполненные этапы

- подготовлена и проверена выборка Geo Reviews из 1 000 отзывов;
- сформированы разбиения `Original` 700/150/150 и `Manual` 900/150/150;
- проверены 200 размеченных отзывов Otzyvru: согласие 199/200, Cohen's Kappa 0,990;
- проверены 34 000 изображений и аннотации подмножества HaGRIDv2;
- отобраны и проверены двумя участниками 200 дополнительных изображений;
- сопоставлены экспорты HaGRID: совпадение классов 200/200, Cohen's Kappa 1,000, 199 точных совпадений bbox.

Искусственное обогащение и обучение моделей ещё не выполнялись.


## Воспроизводимость

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Порядок размещения локальных данных и основные команды приведены в [data/README.md](data/README.md). Исходные датасеты, полные тексты отзывов, изображения и пользовательские экспорты не включаются в Git.
