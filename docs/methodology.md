# Методология исследования

## Исследовательская задача

Исследование оценивает влияние способа обогащения данных на качество и устойчивость моделей машинного обучения. Сравниваются четыре режима при одинаковых исходных выборках, моделях и условиях оценки:

1. `original` — только исходная рабочая выборка;
2. `manual` — исходные данные и новые реальные объекты с ручной разметкой;
3. `synthetic` — исходные данные и искусственно созданные объекты;
4. `combined` — совместное ручное и искусственное обогащение.

## Постановки задач

### Geo Reviews

Задача — бинарная классификация тональности русскоязычных отзывов о заведениях быстрого питания. Из полного Geo Reviews планируется отобрать 150–200 текстов. Оценки 1–2 рассматриваются как предварительная отрицательная метка, 4–5 — как положительная. Оценки 0 и 3 не включаются в рабочую схему до отдельного решения.

Поле `rating`, адрес и название организации не используются как признаки модели. Разметка тональности должна быть проверена независимо от оценки пользователя.

### HaGRIDv2

Используемое подмножество допускает две постановки: классификацию основного жеста по полному кадру и детекцию жестов по ограничивающим прямоугольникам (bounding box, bbox). Перед формированием выборок необходимо выбрать одну основную постановку, набор целевых классов и правила интерпретации двухручных жестов.

## Ручное обогащение

Ручное обогащение предполагает получение новых реальных примеров в той же предметной области и их разметку по заранее утверждённому регламенту.

Для текстов регламент должен определять:

- положительную, отрицательную, нейтральную и смешанную тональность;
- обработку сарказма и бессодержательных отзывов;
- порядок разрешения конфликта между текстом и рейтингом.

Для изображений регламент должен определять:

- границы классов жестов;
- правила построения bbox;
- частичную видимость и окклюзию;
- случаи с несколькими руками;
- использование класса `no_gesture`.

## Искусственное обогащение

Искусственное обогащение должно создавать новые варианты только на основе обучающей выборки. Для текстов необходимо сохранять исходную метку и смысл отзыва. Для изображений геометрические преобразования должны применяться одновременно к изображению и bbox.

Конкретные методы генерации и аугментации ещё не выбраны. Их параметры должны быть одинаково документированы для всех экспериментальных режимов.

## Формирование выборок

Обучающая, валидационная и тестовая выборки формируются до обогащения данных и остаются неизменными во всех режимах.

- одинаковые или нормализованно совпадающие тексты Geo Reviews включаются только в одну выборку;
- изображения HaGRIDv2 группируются по `user_id`;
- записи без `user_id` распределяются только после утверждения отдельного правила;
- производные варианты объектов из валидационной и тестовой выборок не включаются в обучение;
- точные и визуально сходные изображения не должны пересекать границы выборок.

## Экспериментальный контроль

Для сопоставимости режимов фиксируются:

- исходное разбиение данных;
- инициализация генератора случайных чисел;
- архитектура модели;
- гиперпараметры;
- бюджет обучения;
- объём добавленных данных;
- критерии ранней остановки и выбора контрольной точки.

Если объёмы обогащения различаются, это учитывается как отдельный фактор анализа.

## Метрики

Для классификации текстов и жестов планируются:

- macro-F1;
- precision и recall по классам;
- balanced accuracy;
- матрица ошибок;
- анализ качества на содержательных подгруппах.

Для детекции жестов дополнительно планируются:

- mAP;
- precision и recall по классам;
- метрики по размерам объектов, окклюзии и числу рук в кадре.

## Состояние методологии

Валидация исходных данных и EDA выполнены. Рабочие выборки, протоколы ручной разметки, методы искусственного обогащения, модели и окончательные метрики экспериментов находятся на этапе проектирования. Обучение моделей не проводилось.
