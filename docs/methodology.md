# Методология исследования

## Исследовательская цель

Проект сравнивает влияние ручного, синтетического и совместного обогащения на качество и устойчивость моделей для текстовой классификации и Object Detection. Сравнение должно отделять эффект способа обогащения от эффекта объёма данных, разбиения и настройки модели.

## Постановки задач

### Geo Reviews

Предварительная задача — бинарная классификация тональности русского текста. Рейтинги 1–2 задают слабую отрицательную метку, 4–5 — слабую положительную. Рейтинги 0 и 3 не включаются до отдельного решения. `rating`, адрес, название организации и производная целевая метка не используются как признаки при предсказании тональности по тексту.

Рекомендуемая первая рабочая выборка — 2 400 отзывов, по 1 200 каждого класса, со стратификацией по длине и категории. Это рекомендация EDA, а не утверждённая конфигурация эксперимента.

### Hard Hat Workers

Исходная задача содержит три класса: `head`, `helmet`, `person`. EDA показал 615 рамок `person` против 6 677 `head` и 19 747 `helmet`, а выборочный аудит обнаружил видимого человека без `person`-рамки. Двухклассовая схема `head`/`helmet` рекомендуется как основной кандидат, но не считается утверждённой. Исходные аннотации не изменяются.

## Протокол сравнения

Планируются четыре режима:

1. original — только исходная рабочая выборка;
2. manual — исходная выборка плюс новые реальные объекты с двойной ручной разметкой;
3. synthetic — исходная выборка плюс искусственно созданные объекты;
4. combined — совместное ручное и синтетическое обогащение.

Для корректного сравнения фиксируются random seed, split, архитектура модели, гиперпараметры, бюджет обучения и независимый test. Объём добавленных данных должен быть сопоставим либо явно учитываться в анализе.

## Предотвращение утечек

- Train/validation/test фиксируются до любого обогащения.
- Производные варианты validation/test не попадают в train.
- Одинаковые нормализованные тексты Geo Reviews группируются до split.
- Для изображений проверяются точные и, при необходимости, почти одинаковые кадры между частями.
- Синтетические изображения создаются вместе с корректным преобразованием Bounding Boxes.
- Рейтинг Geo Reviews не используется как входной признак.

## Оценка качества и устойчивости

Для классификации предполагаются macro-F1, per-class precision/recall, balanced accuracy и срезы по длине, категориям и неоднозначным формулировкам. Для Object Detection предполагаются mAP, precision/recall по классам и срезы по размеру объекта, плотности сцены, разрешению и окклюзии. Конкретные модели и пороги пока не выбраны.

## Ручная разметка

До начала разметки создаются отдельные codebook:

- для текста — положительная/отрицательная тональность, смешанный отзыв, сарказм, бессодержательный текст, конфликт текста и рейтинга;
- для изображений — определения классов, tight box, частичная видимость, окклюзия, минимальный объект и правила плотных сцен.
